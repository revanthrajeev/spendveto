Privacy Policy

Last updated July 2026

SpendVeto is open-source software you can self-host. This policy covers two separate things: (1) this marketing/waitlist website, and (2) the SpendVeto software itself when you run it.

This website

  • Waitlist signup — if you join the waitlist, we store the email address you provide, solely to notify you about access and product updates. It is never sold or shared with third parties.
  • No tracking cookies, no ad pixels. This site does not run third-party analytics, advertising trackers, or cross-site cookies.
  • Aggregate stats only. The live counters on the homepage (governed spend, blocked spend) come from your own local server if you're running one — this website does not collect that data centrally.

The SpendVeto software

SpendVeto is self-hosted by design. When you run it (simulate or testnet mode), all data — the ledger, policy configuration, wallet keys, delegation records — stays on your own infrastructure. We do not operate a hosted version that receives your data, and we have no visibility into how you use your own deployment.

  • Wallet keys generated in simulate mode are stored locally in your own data/ directory and are never transmitted anywhere.
  • Optional webhooks (alertWebhookUrl) you configure send freeze/block/approval events only to the endpoint you specify — that's your infrastructure choice, not ours.
  • Testnet/mainnet payments settle on public blockchains (e.g. Base Sepolia), which are inherently public ledgers by design — that visibility comes from the chain, not from SpendVeto.

Changes

If this policy changes materially, the "last updated" date above will change and, where required, we'll notify waitlist subscribers by email.
