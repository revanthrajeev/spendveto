Give every agent a hard dollar budget for LLM calls.

An agent in a loop can burn through an API budget in minutes. SpendVeto sits between the agent and the model: it estimates each call's worst-case cost, checks it against the agent's budget, and refuses before the model is called — with a machine-readable reason the agent can act on. One command shows it.

Try it — one command

git clone https://github.com/revanthrajeev/spendveto && cd spendveto && npm install
npm run quickstart:ai

It boots the server and proxy locally, gives a fresh agent a $0.0015 budget, and lets it call until the budget is gone. A real run:

  call  1  ALLOWED  $0.000209   running total $0.000209
  call  2  ALLOWED  $0.000209   running total $0.000418
  ...
  call  6  ALLOWED  $0.000209   running total $0.001254
  call  7  BLOCKED  [delegation_cap] remaining budget on this line is $0.0002 — pick a cheaper
                    tool that fits, or request a top-up grant from "quickstart-..."
  call  8  BLOCKED  [delegation_cap] ...

  6 calls allowed ($0.001254 of $0.0015), 2 refused before reaching the model.
  audit ledger hash-chain intact: true

Costs shown use the proxy's configured token rates (LLM_RATE_IN_PER_M / LLM_RATE_OUT_PER_M, default $1 per million tokens) — set them to your provider's price. With no ANTHROPIC_API_KEY the completions are simulated; governance and metering are real. Set the key for real model calls.

Three lines in your agent

JavaScript

import { SpendVeto } from "spendveto-sdk";
const sv = new SpendVeto({ agentToken });
const reply = await sv.chat(prompt);
// throws SpendVetoDenialError
// once the budget is gone

Python

from spendveto import SpendVeto
sv = SpendVeto(agent_token=token)
reply = sv.chat(prompt)
# raises SpendVetoDenialError
# once the budget is gone

The Python client is in sdk-python/ (standard library only; install with pip install ./sdk-python — a PyPI release is pending).

What stands between the agent and your bill

Per-agent budget

Nested caps down a hierarchy of agents and sub-agents. A child can never out-spend its parent's grant.

Fails closed

Over a cap, over a rate limit, frozen, or an unanswered human approval: the model is never called.

Self-correcting refusals

Every denial carries a code and a concrete fix, so the agent picks a cheaper path instead of retry-looping.

Kill switch

A runaway burst auto-freezes the agent mid-loop; a human unfreezes it after review.

Human approval

Calls above a threshold pause for a real approve or deny.

Tamper-evident audit

Every decision lands in a hash-chained ledger you can verify and export.

What this is not. It meters spend at the rates you configure; it does not read your provider's invoice, and it is not a replacement for provider-side hard limits — it is the agent-aware layer in front of them. Self-hosted today; a hosted, multi-tenant version is the funded milestone.
